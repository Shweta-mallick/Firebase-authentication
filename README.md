# Firebase-authentication
An authentication system implemented using firebase.
<br>
STEPS TO INSTALL THE PROJECT ==============
<br>
1. Clone the repository <br>
2. run the "npm install" command <br>
3. The ".env.example" file has all the environment variables required for firebase configuration. <br>
4. Create a ".env" file and copy the firebase config variables as stated in the ".env.example" file. <br>
5. run "npm run dev".
